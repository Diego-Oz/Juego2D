# 🛸 Juego2D — Space Defender

Juego 2D desarrollado en **Unity con C#** donde controlas a un alienígena que debe defender su nave espacial 
de globos tóxicos de colores. Dispara rayos láser para destruirlos antes de que impacten la nave — 
cada globo destruido suma puntos, cada impacto cuesta una vida.

> Proyecto académico — ITLA

---

## 🎮 Mecánicas principales

- 🔫 **Láser recargable** — el arma principal tiene un sistema de carga, no puedes disparar sin límite
- 🎈 **Globos tóxicos** — enemigos de colores que avanzan hacia la nave con distintos comportamientos
- ❤️ **Sistema de vidas** — cada globo que toca la nave reduce una vida
- 🏆 **Puntuación** — cada globo destruido suma al marcador
- 💀 **Game over** — al perder todas las vidas termina la partida

---
